# Forge PHP 1.4.1 review

## Follow-up release 1.4.2

Toolchain diagnostics now check Composer's locked platform requirements with plugins and scripts disabled, compare the selected PHP runtime with the language target, and report the selected project's Git status and root .env tracking. PHPUnit and quality checks save open files first and stop on a failed save. All 24 unit tests and ESLint pass. The dependency versions and outstanding findings below also apply to 1.4.2.

The diagnostics command was exercised inside the IDE against the Welcome project and a disposable fixture. The fixture correctly reported an incompatible PHP requirement, a language/runtime version mismatch, and a tracked root .env. Its placeholder credential content was absent from the report.

The packaged 1.4.2 app also passed the diagnostics command against Welcome using its own bundled PHP and Composer. The installer payload passed archive verification, and SHA256SUMS-1.4.2.txt accompanies it. GitHub was checked after building and still offered v1.4.0. Publishing the updated source and 1.4.2 assets remains required before downloading these fixes from GitHub.

Reviewed on Windows x64 on 15 November 2026. The application remains a custom IDE with outstanding dependency findings and project-specific verification required before relying on it for client delivery.

## Corrections

- Formatting captures the document version and discards results when newer edits arrive during formatting. This covers project PHP formatters and the built-in Prettier provider.
- Documentation downloads use extension storage in the user profile. Bundled articles remain available offline, including when the installation directory is read-only.
- DOMPurify is pinned to 3.4.18 throughout the desktop dependency tree, replacing the vulnerable editor copy.

## Verification

- ESLint passes. All 23 unit tests pass, including three new regressions for formatting races and offline documentation.
- All 16 IDE integration checks pass after the fixes, using the bundled Welcome project and a separate settings profile.
- The integration checks exercise PHP completion, go-to-definition, diagnostics, formatting, save-time formatting, documentation, terminal execution, process tasks, Xdebug stop/stack inspection, Git repository detection, HTTP code lenses, an actual HTTP request, local history, bookmarks, and detaching and restoring an editor.
- The desktop production dependency audit reports 0 critical, 0 high, 36 moderate, and 14 low findings. Counts include affected parent dependencies. Direct advisory sources remaining include glob, minimatch, uuid, deepmerge, and @tootallnate/once.
- The Forge extension production dependency audit reports zero findings.
- The packaged 1.4.1 executable launches with a fresh profile and registers the Git, assistant, and Intelephense installation commands. Its compiled frontend contains DOMPurify 3.4.18, and the packaged formatter and documentation files match the reviewed source.

## Remaining verification and limits

- The integration project runs with the bundled PHP 8.4. Match the interpreter and Intelephense PHP target to each client project's supported PHP version and run that project's tests.
- A fresh physical work PC installation, client database connectivity, deployment, remote interpreters, GitHub write operations, and live cloud AI calls were outside this review's exercised scenarios.
- The environment status displays .env metadata. PHP configuration and process environment can override it. Confirmation applies to Forge-owned database commands. Terminal commands and Composer scripts can also mutate databases.
- Gemini project lookups send code excerpts to Google when enabled. Configure cloud usage according to the client's data handling requirements.
- The installer is unsigned. Automated updating and long-duration recovery testing remain outstanding.
- Existing 1.4.0 downloads do not receive these fixes automatically. Install the 1.4.1 asset and publish the matching source changes when distributing it.
